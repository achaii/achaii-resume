# Deni Hidayat — Principal Software Engineer Portfolio & CV

Website portfolio & curriculum vitae interaktif modern berbasis **Next.js 16 (App Router)**, **TypeScript**, dan **Tailwind CSS**. Didesain dengan estetika modern, dukungan dwi-bahasa (English & Bahasa Indonesia), mode gelap & terang, print/export PDF resume, menu mobile responsif, dan favicon developer suite kustom.

---

## 🚀 Fitur Utama
- **Next.js 16 (App Router) & React 19**: Rendering super cepat dan performa optimal.
- **Dwi-Bahasa (English & Bahasa Indonesia)**: Toggle bahasa instan (EN/ID) tanpa reload halaman.
- **Mode Gelap / Terang**: Otomatis mendeteksi preferensi sistem dengan opsi toggle manual.
- **Export & Cetak CV (PDF)**: Tombol cetak khusus yang diformat presisi untuk kertas standar tanpa elemen navigasi.
- **Mobile Responsive**: Menu burger drawer yang rapi dan navigasi ramah sentuhan.
- **SEO & Social Sharing Ready**: Metadata OpenGraph dan Twitter Card lengkap.
- **Identitas Personal**: Menggunakan foto profil Instagram [@dennyachaii](https://www.instagram.com/dennyachaii) untuk logo brand.

## 🛠️ Menjalankan di Lokal (Development)

1. Pastikan dependensi sudah terinstall:
   ```bash
   npm install
   ```

2. Jalankan server development:
   ```bash
   npm run dev
   ```

3. Buka browser di [http://localhost:3000](http://localhost:3000).

4. Untuk memvalidasi build produksi:
   ```bash
   npm run build
   ```
